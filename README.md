# PDS VIVA — BE05000231

Python for Data Science viva preparation website for Semester 5.

## Source boundary
- `BE05000231` is the only syllabus authority.
- The question bank is based on the previously generated PDS Q&A and keeps its original question IDs/order where retained.
- Exact duplicate questions are removed from the rendered bank.
- No unrelated subject or unsupported syllabus topic is added.

## Features
- Answers are always visible.
- Top 20, Important, Low Priority, Tricky, Rapid Fire and Revision sections.
- Unit 1 → Unit 7 official ordering.
- Search across questions, answers, keywords and topics.
- Combined priority/unit filters and sorting.
- Studied and saved/bookmark state with localStorage.
- Random question and keyboard shortcuts.
- Quiz using only the existing question bank; answers remain visible.
- Responsive layout for desktop, 4K, tablet and mobile.
- Reduced-motion accessibility support.

## Run
Open `index.html` directly in a modern browser. No Node, React, TypeScript, Bootstrap or build step is required.
